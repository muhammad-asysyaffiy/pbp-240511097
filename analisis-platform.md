# Analisis Komparatif Platform & Refleksi

## 1. Tabel Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa utama** | HTML, CSS, JavaScript (React, Vue, Node.js) | C++, C#, Java, Python, Electron (JS) | Kotlin (Android), Swift (iOS), Dart (Flutter) |
| **Arsitektur** | Client-Server (diakses via Browser) | Standalone (Native) atau Client-Server | Standalone (Native) atau Client-Server |
| **Cara distribusi** | Diakses langsung melalui URL di Browser | File Installer (.exe, .msi, .dmg) atau App Store OS | Toko aplikasi (Google Play Store, Apple App Store) |
| **Keunggulan** | Lintas platform (dapat dibuka di OS apa saja), tidak perlu instalasi | Performa tinggi, dapat berjalan offline, akses penuh ke hardware | Sangat portabel, mendukung sensor khusus (GPS, Kamera, Accelerometer) |
| **Keterbatasan** | Sangat bergantung pada koneksi internet, performa dibatasi browser | Harus diinstal manual, pembaruan aplikasi rumit, terikat OS | Ukuran layar terbatas, daya baterai dan memori terbatas |
| **Contoh aplikasi** | Google Docs, GitHub, Tokopedia Web | Microsoft Word, Adobe Photoshop, VS Code | WhatsApp, Instagram, Gojek |

## 2. Refleksi

Di antara ketiga platform yang ada, platform Web adalah yang paling menarik untuk saya pelajari. Alasannya karena platform Web memiliki sifat lintas platform (cross-platform) yang sangat fleksibel, di mana satu aplikasi yang dibangun dapat langsung diakses dari berbagai jenis perangkat dan sistem operasi tanpa perlu proses instalasi yang rumit. Selain itu, ekosistem teknologi Web seperti JavaScript dan berbagai framework-nya berkembang sangat pesat.

Tantangan terbesar yang saya hadapi saat melakukan setup environment adalah melakukan konfigurasi awal dan pemahaman terhadap command line terminal, terutama saat memasang Java JDK serta mengatur Environment Variables di Windows agar perintah terminal dapat mengenali lokasi instalasi Java dengan benar. Selain itu, memahami cara kerja integrasi antara Git lokal dan GitHub juga membutuhkan ketelitian ekstra agar tidak terjadi kesalahan pemanggilan perintah.

Rencana saya untuk mengatasi tantangan tersebut adalah dengan melatih penggunaan perintah dasar Git dan terminal secara rutin, membaca dokumentasi resmi dari setiap tools yang diinstal, serta tidak ragu mencari solusi melalui komunitas pengembang atau panduan teknis jika menemukan error pada sistem.
